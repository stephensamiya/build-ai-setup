## Teach once
- When I correct you, or say "remember", "always", "never" or "from now on",
  stop and propose saving it before you continue. Decide which kind it is:
  - a preference about how I work: add a line to ~/ai-context/memory/always.md
  - a fact or gotcha: add an entry to ~/ai-context/docs/tips.md
  - a procedure for a task: create or update ~/ai-context/skills/<name>/SKILL.md
- Search the target file first. If a matching entry exists, update it instead.
- Show me the exact edit. Write it only after I say yes, then commit it.
